# 复盘

关键取舍是模型自主选工具、程序强制证据边界。只检查 quote 不能防止“有效引用加编造结论”，因此采用摘录答案格式；代价是 Guard 拒绝和模型修订次数增加，真实冲突路径已记录。

实际环境问题：沙箱禁止下载；pip 全局附加源持续 TLS 失败；重定向 TEMP 拒绝 metadata 原子写入；Windows asyncio socketpair 在沙箱阻塞。分别通过受控联网、仅本进程禁用附加源、项目内部临时目录、允许回环的测试环境解决，没有改系统安全策略。

扫描器初版的空白正则跨行误报 env 模板，修正为仅空格/制表符；失败 Gate 保留。扩展 32 篇后，离线模拟器因“公司”通用词误用发票制度回答奖金，修正模拟器主题一致性并复跑；live 模型没有使用该启发式。

负面实验：Hybrid 已接近小语料上限，Query Rewrite 没改善 Recall/MRR，却增加调用和延迟。保持固定标签、全部错例和逐题 Trace，没有删难题或改标签。

本轮发现 TC02 三次 Guard 拒绝是缺后缀或换行的排版问题，现由服务端统一排版且不放宽 Guard。P7 已实现，首次注入评测只修正 3/4，其中冲突用例因重复补查耗尽共享预算；增加已读引用和剩余预算反馈后，以完全相同的用例、指标和上限复测。Critic 也曾输出不一致的结构化结果，受控失败已保留，并加强一致性提示和安全诊断。所有尝试见质量报告。

下一步：扩大独立标注数据，建模范围关系和效力元数据，评估长文 chunk 边界、语义相关性与多用户权限。引用 100% 有效不等于任意语义答案正确；P7 小型受控实验也不能代表自然场景收益。真实时间跨度与本轮用时分开记录。
