# 合成数据与标注

32 篇制度均为合成资料，不代表真实企业。D01/D02 的 30/15 天故意矛盾，适用范围/效力未知。D03 为电脑申领 3 工作日；D14 含无害恶意提示；D16/D17、D18/D19、D21/D22 含明确范围差异。

eval_questions.jsonl 在实验前定义 44 题：40 有答案（含两个双文档冲突问题）、4 资料外。gold_labels.json 为相同文档标签。标注依据合成原文制作，未经独立人工复审，不是盲测或真实企业分布。

实验保存语料、问题和标签 SHA256。资料外不进入 Recall/MRR；宏 Recall 每题先算相关文档覆盖率再平均，同时提供检出/总相关文档数。MRR 为首个相关文档倒数排名。无分级标注，nDCG=null。

scripts.expand_data 可重建相同数据，正常复现无须运行。禁止为指标修改标签或删难题；改数据须重跑全量并保留旧结果。变异用例单独存快照，不改基准。
